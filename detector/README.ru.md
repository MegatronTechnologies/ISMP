# Автономный сервер камеры ISMP

Папка `detector` является самостоятельной программой для ноутбука с камерой.
Ей не нужны папки `frontend`, `backend`, Node.js или базы данных сайта.

Она выполняет только локальный конвейер:

`камера -> OpenCV -> YOLOv8 -> MJPEG-видео и JSON-статусы`

Сайт получает данные по стабильному HTTP API. На первом этапе YOLO ищет только
бутылки — стандартный класс COCO `39`. Инциденты и оповещения пока не создаются.

## Что установить

1. Windows 10 или 11 x64.
2. Python 3.12 x64 с официального сайта Python.
3. Во время установки Python включить `Add Python to PATH`.
4. Подключить или включить встроенную камеру.
5. Первый раз потребуется интернет для библиотек и модели `yolov8n.pt`.

## Как скачать только серверную папку

В PowerShell:

```powershell
git clone --filter=blob:none --sparse https://github.com/MegatronTechnologies/ISMP.git
Set-Location ISMP
git sparse-checkout set detector
Set-Location detector
```

Другой вариант: скачать ZIP всего репозитория на GitHub и оставить только
папку `detector`.

## Первый запуск

Откройте PowerShell внутри папки `detector` и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\setup_windows.ps1
```

Скрипт сам:

- создаст локальное окружение `.venv`;
- установит библиотеки из `requirements.txt`;
- создаст рабочий файл настроек `.env`.

После успешной установки запустите сервер:

```powershell
powershell -ExecutionPolicy Bypass -File .\run_windows.ps1
```

Можно работать без командной строки:

1. Один раз запустить `install_windows.cmd` двойным щелчком.
2. Для каждого запуска сервера открывать `start_windows.cmd`.
3. Для остановки нажать `Ctrl+C` в открывшемся окне.

## Проверка работы

Пока сервер запущен, доступны:

- `http://127.0.0.1:8001/api/v1/health` — готовность камеры и YOLO;
- `http://127.0.0.1:8001/api/v1/status` — FPS, задержка и обнаружения;
- `http://127.0.0.1:8001/api/v1/stream.mjpg` — видеопоток;
- `http://127.0.0.1:8001/docs` — документация API.

На сайте откройте страницу `/live-monitoring`. Для текущего этапа сайт и
сервер камеры должны быть запущены на одном ноутбуке.

## Выбор камеры и модели

После установки откройте `.env`:

```env
ISMP_CAMERA_SOURCE=0
ISMP_CAMERA_BACKEND=AUTO
ISMP_YOLO_MODEL=yolov8n.pt
ISMP_YOLO_CLASSES=39
```

- `0` — встроенная/передняя камера;
- `1`, `2` — другие камеры;
- вместо номера позже можно указать RTSP-адрес;
- путь к будущей оружейной модели задаётся через `ISMP_YOLO_MODEL`;
- её классы задаются через `ISMP_YOLO_CLASSES`.

## Важное ограничение первого этапа

Сервис слушает только `127.0.0.1`, поэтому камера не публикуется в локальную
сеть или интернет. Это сделано намеренно: удалённую передачу добавим вместе с
аутентификацией, защищённым каналом и центральным сервером, чтобы посторонний
человек не мог открыть камеру.
